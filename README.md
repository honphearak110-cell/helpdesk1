# IT Helpdesk

ប្រព័ន្ធគ្រប់គ្រងសំណើជំនួយបច្ចេកទេស សាងសង់ដោយ Next.js, React, Drizzle ORM និង PostgreSQL។ ប្រសិនបើមិនអាចភ្ជាប់ PostgreSQL បាន ប្រព័ន្ធប្រើឯកសារ `.helpdesk-data/database.json` ក្នុងម៉ាស៊ីនជំនួស។ ទិន្នន័យទាំងពីរនេះជាឃ្លាំងដាច់ដោយឡែកពីគ្នា។

## ដាក់ ឬប្ដូររូបភាពអ្នកប្រើប្រាស់

1. ចូលគណនី ហើយជ្រើស **គណនីផ្ទាល់ខ្លួន** នៅម៉ឺនុយខាងឆ្វេង។
2. នៅផ្នែក **រូបភាពគណនី** ចុច **ជ្រើសរើសរូបភាព** ឬទាញឯកសាររូបភាពដាក់ក្នុងផ្ទាំង។ អាចប្រើ JPG, PNG, WebP ឬ GIF ទំហំឯកសាររហូតដល់ 12 MB។ ប្រព័ន្ធកាត់កណ្ដាល និងបន្ថយទំហំរូបដោយស្វ័យប្រវត្តិ។ ក៏អាចដាក់តំណរូបភាព HTTP(S) ដែលអាចបើកបានផងដែរ។
3. មើលរូបជាមុន រួចចុច **រក្សាទុកព័ត៌មាន**។ ប្រសិនបើចង់ដករូប ចុច **លុបរូប** ហើយរក្សាទុក។ បើគ្មានរូប ប្រព័ន្ធបង្ហាញអក្សរដំបូង និងពណ៌ដែលបានជ្រើស។
4. Admin អាចដាក់ ឬប្ដូររូបឲ្យអ្នកប្រើប្រាស់ផ្សេងនៅ **អ្នកប្រើប្រាស់ → កែប្រែ** ឬពេលបន្ថែមគណនី។ រូបបង្ហាញនៅក្នុងម៉ឺនុយគណនី បញ្ជីអ្នកប្រើប្រាស់ សំណើ និងការសន្ទនា។

រូបដែលបាន upload រក្សាទុកក្នុង PostgreSQL ឬក្នុងឯកសារ JSON អាស្រ័យលើរបៀបផ្ទុកដែលកំពុងប្រើ។ ការប្ដូរគណនីពីម៉ឺនុយខាងលើតម្រូវឲ្យបញ្ចូលពាក្យសម្ងាត់របស់គណនីដែលចង់ប្ដូរ។

## ដំណើរការលើម៉ាស៊ីនផ្ទាល់

1. ដំឡើង Node.js និង PostgreSQL។ កំណត់ `DATABASE_URL` ក្នុង `.env` ឲ្យត្រូវនឹង PostgreSQL របស់អ្នក (អាចចម្លងពី `.env.example` សម្រាប់ការដំឡើងថ្មី)។ ប្ដូរ `AUTH_SECRET` ទៅជាតម្លៃចៃដន្យដ៏វែង និងរក្សាវាជាសម្ងាត់។
2. បើក terminal ក្នុង folder របស់ project ហើយដំណើរការ៖

   ```bash
   npm install
   npm run dev
   ```

3. បើក `http://localhost:3000`។ នៅ Windows អាចចុច `start-helpdesk.bat` ដើម្បីសម្អាត cache និងដំណើរការ។

នៅ PostgreSQL ថ្មី ប្រព័ន្ធបង្កើតតារាង និងគណនីគំរូពេលដំណើរការលើកដំបូង។ នៅ database ដែលមានអ្នកប្រើប្រាស់រួច ប្រព័ន្ធបន្ថែម column សម្រាប់រូបភាពដោយមិនលុបអ្នកប្រើប្រាស់ចាស់ និងមិនបង្កើតគណនីគំរូឡើងវិញទេ។ គណនី PostgreSQL ត្រូវមានសិទ្ធិ `CREATE` និង `ALTER` ដើម្បីរៀបចំតារាង។ ប្រសិនបើការភ្ជាប់ ឬការកែតារាងបរាជ័យ ប្រព័ន្ធបង្ហាញថាកំពុងប្រើ Local ជំនួស។

## គណនីគំរូសម្រាប់ database ថ្មី

| គណនី | Username | ពាក្យសម្ងាត់ដំបូង |
| --- | --- | --- |
| Admin | `admin` | `123456` |
| IT Agent | `agent` | `123456` |
| Staff | `user` | `123456` |

ប្ដូរពាក្យសម្ងាត់គំរូ និងពិនិត្យការកំណត់សុវត្ថិភាពមុនដាក់ប្រើលើបណ្ដាញពិត។

## ធ្វើបច្ចុប្បន្នភាព project ដែលមានរួច

1. បិទ server ហើយបម្រុងទុក PostgreSQL និង folder `.helpdesk-data` របស់អ្នកជាមុន។
2. ពន្លា archive ចូល project ហើយជំនួសឯកសារ source ចាស់។ Archive មិនមាន `.env`, `drizzle.config.json` ឬ `.helpdesk-data` ដូច្នេះការកំណត់ និងទិន្នន័យចាស់មិនត្រូវបានជំនួសទេ។ សម្រាប់ project ថ្មី អាចចម្លង `.env.example` និង `drizzle.config.example.json` ទៅឈ្មោះឯកសារពិត ហើយកែការកំណត់របស់អ្នក។
3. នៅ Windows Command Prompt៖

   ```bat
   npm install
   if exist .next rmdir /s /q .next
   npm run dev
   ```

   ឬចុច `start-helpdesk.bat`។ បើអ្នកប្រើ PowerShell អាចលុប cache ដោយ `Remove-Item -Recurse -Force .next` ជំនួស។
